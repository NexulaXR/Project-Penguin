Podstawowe komendy Linuxa

ls

ls służy do wyświetlania zawartości bieżącego katalogu

Przykład użycia

            $ ls
            images
            index.html
            linux.html
            komendy.html

cd

cd służy do zmienienia katalogu w którym aktualnie się znajdujesz (jak sama nazwa wskazuje c=change d=directory)

Przykład użycia

                $ cd /home/nazwa_użytkownika/nvidia

pwd

pwd służy do wyświetlenia katalogu w którym aktualanie się znajdujesz

Przykład użycia

                $ pwd
                /home/nazwa_użytkownika

mkdir

mkdir służy do tworzenia katalogu (jak sama nazwa wskazuje mk=make dir=directory)

Przykład użycia

                $ mkdir documents

sudo

sudo jest skrótem od super user do czyli w wolnym tłumaczeniu super użytkownik wykona komenda pozwala wykonywać operację jako root

Przykład użycia

                $ sudo apt install steam
