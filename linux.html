Czym jest Linux?

Czym właściwie jest Linux?

Linux to jądro (kernel) stworzone przez Linusa Torvalda w 1991 roku na podstawie Unixa. W połączeniu z innymi komponentami tworzy system operacyjny taki jak Debian czy Arch Linux.

Czym jest dystrybucja Linuxa?

Dystrybucja Linuxa to cały gotowy system operacyjny który można pobrać i odrazu użytkować. Dystrybucja to taki "zestaw" rzeczy które są potrzebne by korzystać z systemu takie jak kernel środowisko graficzne czy podstawowe aplikacje np Terminal by móc zarządzać systemem.

Najpopularniejsze dystrybucje linuxa

Najpopularniejszą dystrybucją Linuxa jest zdecydowanie Ubuntu ale jest takich wiele więcej np:

  • Debian - Najbardziej znany jest ze swojej stabilności
  • Fedora - Najbardziej znany jest ze swojej prostoty oraz dedykowanych pakietów np. Davinci Resolve
  • Arch Linux - Najbardziej znany jest z jego możliwości konfiguracji i trudności instalcji

Jak wybrać dystrybucję dla siebie?

To wszystko zależy, czego wymagasz od systemu!

  • Chcesz prostoty - Linux Mint albo Ubuntu
  • Chcesz stabilności - Debian albo Fedora
  • Chcesz dużej kontroli - Arch Linux albo NixOS
  • Chcesz czegoś dla początkującego - Linux Mint albo Bazzaite

Dystrybucji Linuxa są setki a nawet tysiące, każdy znajdzie więc coś dla siebie nawet jeżeli nie jest to najprostsza odpowiedź

Podstawowe pojęcia

  • Kernel - jądro systemu jego serce pozwala mu działać
  • Dystrybucja - gotowy system z menadżerem paczek środowiskiem graficznym i innymi
  • Terminal - pozwala zarządzać systemem tworzyć usuwać etc. oraz instalować aplikacje
  • GUI - pulpit pasek zadeń i okienka pozwala korzystać z systemu graficznie
